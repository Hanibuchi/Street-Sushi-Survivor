# Street Sushi Survivor (ストリート寿司サバイバー)

「一貫の妥協も許さない。俺は、都会の寿司を喰らい尽くす。」
[![Play Game](https://unityroom.com/games/street_sushi_survivor)]

森から降りてきた一頭の熊となり、大都会の路上に落ちている寿司を制限時間内に食べまくる、3D見下ろし型「寿司・捕食・アクション」ゲーム。

## 🐻 ゲーム概要
プレイヤーは、都市をモデルにしたステージを舞台に、迫りくる車や罠を避けながら、一粒でも多くの寿司を食べることを目指します。

## 🍣 ゲームシステム

### 1. タイムアタック & ラウンド進行
* **ラウンドクリア:** 各ラウンドの目標数を食べると次のラウンドへ。
* **追加時間:** ラウンドが進むごとに残り時間が追加されます。後半ほど目標数はシビアになります。
* **時間の流れ:** 1日の中に「朝・昼・夕」のサイクルがあり、1日を終えると特別なボーナスを獲得。

### 2. ローグライク・ビルド
ラウンド間にランダムな3つの選択肢からボーナスを選び、熊を強化します。
* **強化リスト:**
    * **移動速度:** ダッシュのキレが増す。
    * **吸収力:** 感知範囲が広がり、より遠くの寿司を吸い込む。
    * **ワサビ耐性:** 踏んだ時のスタン時間を軽減。
    * etc...

### 3. ステージギミック & リスク
* **寿司の鮮度:** 寿司は一定時間でしなびて消滅します。
* **トラップ:** 「ワサビ（スタン）」
* **大通りの恐怖:** 車がぶつかると爆破四散。しかし、低確率で「高級寿司（3つ分）」を積んだ車も出現し、破壊すれば一気にスコアを稼げます。

## 🕹 操作方法
* **移動 (WASD / スティック):** 熊の移動
* **ダッシュ (Shift / ボタン):** 高速移動。障害物回避が攻略の鍵。
* **咆哮 (E / ボタン):** 周囲のトラップを破壊（スキル習得時）
* **UI対応:** スマホプレイも想定したバーチャルパッドを実装。

## 🎨 こだわりポイント
* **納得のUI:** あと1個でクリアのとき、「もうひとつ！」というUIが表示されます。
* **成長の視覚化:** 食べるほどに熊が巨大化し、圧倒的な捕食力を手に入れます。
* **結末のシュールさ:** ゲームオーバー時は銃声と共に倒れますが、その後「動物園で寿司を飽食しているハッピーエンド（？）」へと切り替わります。
